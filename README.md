# Spider — 具身化 AI 猫咪桌宠

Spider 是运行在电脑桌面上的 Electron 猫咪 Agent。饱食、精力和心情会影响它的行为、任务预算与恢复过程；喂食、抚摸、玩耍和休息会反过来改变这些状态。

## 运行

需要 Node.js 和 npm。Windows 下在项目目录执行：

```bash
npm install
npm start
```

安装依赖时，项目中的 `.npmrc` 已配置 Electron 下载镜像。

## 配置 DeepSeek

1. 复制 `config.example.json` 为 `config.local.json`。
2. 在 `config.local.json` 的 `deepseek.apiKey` 中填写自己的 DeepSeek API Key，保留完整的 `baseUrl` 和 `model` 配置。
3. 重启 Spider。

`config.local.json` 和 `data/` 已被 `.gitignore` 排除。不要把真实 API Key 写入源码、截图或提交记录。未配置有效 Key 时，桌宠和动画仍可运行，但模型对话不可用。

## 桌面交互

- **拖动与点击穿透**：只能从猫咪当前帧的非透明像素抓起，透明区域点击直达底层应用；拖动时腹部上提，四条腿按对角分组交替挣扎。
- **点击猫身**：打开聊天与互动面板。
- **喂食 / 抚摸 / 玩耍 / 叫醒**：播放对应的独立动作，并更新身体状态。
- **自主散步**：放松时短距离随机移动，走路动画与窗口位移同步。
- **目光跟随**：放松待机时头部朝鼠标方向转动，支持 8 个方向、近/中/远三档共 25 个姿态；工作、睡觉和互动时停止跟随。
- **睡眠**：启动时先睡觉，默认连续 10 分钟没有与 Spider 互动也会休息；点击“叫醒”播放伸懒腰。
- **主动提醒**：饥饿讨食、无聊求陪、深夜提醒、饭点提醒和过劳提醒具有不同动作。

## Work Buddy 与 AI 文档

聊天窗口上方的“工作伙伴”打开独立面板：

- **专注与休息**：选择 15–90 分钟专注，关联待办，随时暂停、继续或结束；也可以开始 5 分钟短休息。主进程按结束时间戳计时，暂停保留剩余时间，应用重启后恢复会话。
- **今日总结**：在本地统计专注分钟、完成轮次和完成待办，不调用模型。完成专注会消耗与时长对应的精力并增加少量心情；短休息不能代替睡眠。
- **AI 文档创作**：描述主题、读者、用途和篇幅，Agent 会撰写结构化正文并调用 `create_document` 创建可编辑 DOCX 或 Markdown。默认保存到 `Documents/SpiderDocuments`，可在面板中更改和打开目录。
- **诚实降级**：本机 Word 或 COM 不可用时，工具会明确返回 Markdown 文件和警告，不会声称 DOCX 已成功。文档使用唯一文件名，不覆盖已有文件，不创建宏文档；模型不能指定路径、命令或模板。

真实 AI 写作需要配置 DeepSeek API Key。未配置 Key 时，专注、待办、总结和桌宠功能仍可使用。

## 数据备份与安全移除

“工作伙伴 → 数据与移除”提供移除入口。流程必须依次经过确认短语、备份目录选择和 Windows 原生最终确认：

1. 先把白名单状态、记忆、待办、专注记录和合法日期日记备份到 Spider 文件夹之外，**不包含 `config.local.json` 或 API Key**。
2. 最终对话框会显示完整目标与备份路径，并明确警告：整个 `spider-main` 文件夹内的源码、配置和后来放入的所有文件都会一起移动。
3. 只有再次选择“移入回收站”才会启动辅助流程；目标是 Windows 回收站，不是永久粉碎，可以从回收站恢复。

移除目标只由主进程读取，渲染进程不能传入任意路径。程序会检查 Spider 应用标识、真实目录和敏感目录，不删除文件夹之外的任何内容，也不修改既有备份、Electron 漫游配置或外部模型源文件。

## 测试

```bash
npm test
```

测试覆盖专注生命周期与持久化、每日总结、文档唯一命名和 Markdown 降级、卸载目录校验、备份白名单及回收站命令 dry-run。测试不会调用真实付费模型，也不会真实卸载应用。

## 动画架构

猫咪使用透明 PNG 横向精灵图，不依赖 Three.js、GLB 或 Canvas 宠物运行时。资源位于 `assets/cat/`，每帧为 256×192 像素；`assets/cat/animations.js` 定义帧数、FPS 和循环属性。主进程统一裁决拖动、单次互动、工作、睡眠、散步、情绪和待机状态。

## 数据与隐私

身体状态、日记和记忆保存在本机 `data/`。渲染进程启用了上下文隔离并禁用 Node 集成，通过 `preload.js` 暴露受控 IPC 接口。API Key 只由主进程读取，不发送到除所配置模型服务之外的项目代码路径。
